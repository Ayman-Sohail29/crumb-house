# Crumb House 🍰

A responsive home bakery website, built as a **concept project** to practice building a real business-style site with a working cart.

**Live demo:** [LIVE LINK]

## Features
- Responsive layout for desktop and mobile
- Product cards with add-to-cart
- Cart drawer with quantity controls and live total
- Cart saved in the browser with localStorage
- WhatsApp ordering (builds the order message automatically)
- Mobile navigation menu
- Customer reviews section

## Built with
- HTML, CSS, JavaScript
- Vite




## Note
This is a concept project. The WhatsApp number, reviews and contact details are sample data.

## What I learned
- Planning a business website from a design brief
- Managing cart state and quantities with JavaScript
- Saving data with localStorage
- Making a layout responsive
- Deploying with GitHub and Vercel
